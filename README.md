# M3U-Editor

Ein Editor für M3U-Playlisten

---

Ein Editor um M3U-Playlisten zu erstellen und zu Sortieren. Dieser Editor ist für Playlisten optimiert, die TV- und Radio-Programme enthalten. Diese Playliste kann dann z. B. in KODI genutzt werden.

---

## Online ##

Der Editor kann online als Single-Page-Webanwendung (SPA) unter folgender URL genutzt werden:

```
https://kling0ne.github.io/M3U-Editor/
```

---

## Offline ##

Alternativ kann die Datei ``index.html`` heruntergeladen und in einem Browser geöffnet werden.
